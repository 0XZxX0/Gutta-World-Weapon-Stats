# Gutta-World-Weapons

## Important
- Your weapons will still show even if you forget to upload the `data/` folder because `app.js` includes a built-in fallback list.
- Images will only show if you upload your `img/` folder (with `img/weapons/*.png`).

## GitHub upload (web)
1. Open your repo on GitHub.
2. Click **Add file → Upload files**.
3. Drag the **folders** `data` and `img` from your Windows Explorer into the big drop area.
   - GitHub **will not upload empty folders** — make sure the folder contains files.
   - If you have lots of images, upload in smaller batches.

If images still don’t show: open DevTools → Console and look for 404s on `img/weapons/...`.
